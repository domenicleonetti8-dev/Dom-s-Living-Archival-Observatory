PLANETARY COVERAGE

What is actually represented

The map provides a geographic basemap, globe-to-surface navigation, source-backed latitude/longitude anchoring, and authoritative polygon/track rendering where the source publishes geometry.

Health domains remain UNKNOWN unless qualified observations meet D.O.M.'s coverage rules. Network uptime, station inventory and source registration are never substituted for Earth health.

LOCATION MATHEMATICS

Pinpoint when the source supports it; bounded or representative when it does not

Every visible point must carry source-backed latitude/longitude and an explicit location-precision class. WGS84 conversion is deterministic geometry, but source uncertainty is separate. When an upstream product supplies numeric horizontal accuracy, uncertainty radius or confidence, D.O.M. carries those values. When it does not, those fields stay unknown rather than being estimated from decimal places.

Exact source coordinates remain source coordinates. Polygons, forecast cones and track lines remain source geometry. A centroid or representative point is labeled as representative and is never promoted into an exact event location.

D.O.M. may display coordinates to six decimal places for deterministic rendering. Decimal display precision is not a claim of six-decimal physical accuracy. Accuracy is bounded by the upstream instrument, location method, forecast product or source geometry.

A registry entry is not evidence of a connected measurement stream. Browser-capable adapters, broker-required adapters, credentialed services, inventory-only products and specialized scientific products are distinguished instead of collapsed into one misleading coverage count.

GLOBAL SCIENTIFIC INSTRUMENT FABRIC

Target public scientific fields and observing platforms we can lawfully normalize

Loading scientific instrument fabric…

A represented instrument must correspond to a source-backed object with provenance and whatever location/time/state the source actually supplies. Surface stations stay on Earth, marine instruments stay at sea, depth instruments retain depth, and satellites/orbital platforms remain separate from surface geometry. Private, classified, inaccessible or non-geolocated instruments are not invented.

APPLE AR DATA BRIDGE

Same geodetic model, same source coordinates

Checking AR data path…

The AR scene uses the WGS84 reference ellipsoid and converts valid source coordinates into Earth-centered coordinates before scene placement. It carries provenance, observation time, elevation/depth, numeric readings and source-supplied positional uncertainty when available. Missing coordinates, measurements and accuracy values remain null rather than being inferred.

MATH + STATISTICAL OUTLOOK

Predict only when evidence supports prediction

Prediction engine ready for qualified time series.

D.O.M. uses explicit statistical models with sample counts, fit quality, trend significance and prediction intervals. It withholds prediction when there is not enough numeric history and never presents extrapolation as certainty, causal proof or official guidance.

APPLE AR BOUNDARY

Native walk-around AR is a separate client

The web Earth and AR export share a geodetic model and normalized observation contract. The web page is not native room-scale AR. A signed RealityKit client would be required for continuous physical walk-around rendering and must preserve the same source coordinates, uncertainty metadata and provenance.
