TRUTH BOUNDARY

What this page actually is

A lightweight MapLibre geographic globe using OpenStreetMap raster tiles and source-backed points from public agencies.

There is no native Apple AR experience deployed here. There is no signed RealityKit client behind this button, so D.O.M. no longer labels this page as AR.

COORDINATE RULE

Source coordinates only

Visible points are rendered at the latitude and longitude supplied by USGS, NASA EONET, NOAA NDBC, NOAA CO-OPS, or NOAA/NWS when a point coordinate exists. Polygon-only products are not converted into fake point locations on this lightweight page.
